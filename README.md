# YSI LearnPath - National Science, Technology & Innovation Portal

An advanced, production-minded progressive e-learning and national incubation portal modeled after the **Youths & Students in Innovation (YSI)** initiative by the **Federal Ministry of Innovation, Science & Technology (FMIST)** (Ref: `https://ysi.scienceandtech.gov.ng/`).

---

## 1. System Overview & National Vision

The platform equips Nigerian students and youth with mission-critical digital and engineering competencies, bridging the gap between creative academic research and market-ready technology enterprises:

1. **Federal Sovereign Design & Prestige**:
   - Institutional identity: Federal Republic of Nigeria & Federal Ministry of Innovation, Science & Technology (FMIST).
   - Sovereign palette: Deep Executive Slate (`#0B132B`, `#0F172A`), National Emerald Accent (`#047857`, `#059669`), Refined Warm Gold (`#D97706`), crisp off-white canvas.
   - National status bar: Active cohort tracking (`2026/2027 Cohort Active · Virtual Phase · 36 States + FCT Coverage`).

2. **The 5-Stage Progressive Participant Framework**:
   - **Stage 1: Application, NIN Verification & Baseline Screening Pre-Test**: Diagnostic pre-assessment benchmarking candidate digital competencies across software, IoT, clean energy, and hardware.
   - **Stage 2: 3-Week Virtual Intensive**: Prerequisite-gated courses with strict DAG access controls, practical coding exercises, and server-graded assessments.
   - **Stage 3: 3-Day Physical Zonal Innovation Bootcamps**: Hands-on hardware prototyping and robotics labs hosted at federal institutes across Nigeria's six geopolitical zones (Abuja, Lagos, Enugu, Kano, Port Harcourt, Maiduguri).
   - **Stage 4: National Demo Day & Opportunity Desk**: Prototype pitching for access to non-dilutive equity-free seed grants of ₦5,000,000 to ₦25,000,000 and NOTAP patent filing facilitation.
   - **Stage 5: Verified National Certification & Alumni Community**: Cryptographically verifiable credentials (`LP-XXXX-XXXX-XXXX`) linked to the public registry.

3. **8 Specialized National Innovation Tracks**:
   1. *Software, Web & AI Innovation Development*
   2. *Agritech & Agribusiness Innovation*
   3. *Green/Renewable Energy & Climate Innovation*
   4. *HealthTech & Biotechnology Innovation*
   5. *Manufacturing, Hardware & Maker Tech*
   6. *Data Analytics & Innovation Project Management*
   7. *FinTech & Digital Financial Innovation*
   8. *Innovation Branding, Digital Content & Science Communication*

4. **Server-Authoritative Progression Engine**:
   - Strict prerequisite enforcement: locked lessons cannot be bypassed via URL or client-side payload tampering.
   - Cycle detection algorithm preventing circular dependencies.
   - Adaptive Revision Queue automatically mapping missed assessment questions to targeted remediation lessons.
   - Verifiable credentials issued strictly upon server-evaluated course completion.

## 3. How to Run Locally

```bash
# Install dependencies
npm install

# Start full-stack server (Express API + Vite SPA on port 3000)
npm run dev

# Run Vitest unit & integration test suite (7/7 passing)
npm test

# Run TypeScript lint verification
npm run lint
```
